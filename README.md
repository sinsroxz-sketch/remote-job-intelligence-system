# Remote Job Intelligence System (RJIS)

RJIS is an AI-powered career agent designed to reduce the manual effort involved in finding relevant remote jobs.

## Problem

Remote job seekers often spend hours searching multiple job boards, company career pages and LinkedIn, only to discover that many roles are irrelevant, location-restricted or unsuitable for their experience.

## Goal

RJIS will:

1. Read a candidate's resume.
2. Understand their experience and skills.
3. Generate suitable career paths and search strategies.
4. Find fresh remote jobs from multiple sources.
5. Analyse job descriptions.
6. Score each job against the candidate profile.
7. Recommend APPLY, REVIEW or SKIP.
8. Track applications and outcomes.
